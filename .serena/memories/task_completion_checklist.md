# タスク完了時チェックリスト

## 必須
1. **型チェック**: `bun build` でエラーなし
2. **Lint**: `bun lint` でエラーなし
3. **テスト**: 該当テストがあれば実行・パス

## コード変更時
- [ ] DB スキーマ変更 → `drizzle-kit push` 実行
- [ ] 新規コンポーネント → Storybook / 手動確認
- [ ] API 変更 → `packages/api` の型更新
- [ ] 環境変数追加 → `.env.example` 更新 + `packages/config/env.ts` 更新

## コミット前
- [ ] 不要な `console.log` 削除
- [ ] TODO コメント確認・対応
- [ ] 関連ドキュメント更新

## PR 作成時
- [ ] 変更内容の概要記載
- [ ] 破壊的変更の有無明記
- [ ] レビュー観点の提示
